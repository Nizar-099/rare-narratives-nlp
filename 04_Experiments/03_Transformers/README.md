# Transformers — Narrative Classification

This directory documents the Transformer-based experiments conducted as part of the rare narrative classification project.

## Overview

The experiments investigate the use of contextual language representations for multilabel narrative classification in news articles.

Unlike traditional TF-IDF baselines, Transformer models encode words in context, allowing the classifier to capture semantic information beyond surface-level lexical patterns.

## Experimental Analysis

The corresponding experiment artifacts provide material for examining:

- Model performance on coarse and fine narrative labels.
- Differences between contextual and lexical representations.
- Classification behavior on rare narrative categories.
- Model diagnostics and error analysis.
